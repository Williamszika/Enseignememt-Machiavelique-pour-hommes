# Enseignement machiavélique pour hommes — atelier TikTok

Espace de travail pour construire un projet de coaching TikTok destiné aux hommes :
comprendre les enseignements, les décortiquer, puis en tirer des posts, des sujets de
live et des thèmes de discussion.

## Méthode de travail

1. Tu envoies un texte (transcript, article, notes).
2. Il est archivé tel quel dans `sources/` (numéroté).
3. Une analyse est produite dans `analyses/` avec le même numéro :
   - structure et formule rhétorique du texte,
   - ce qui est solide / ce qui est fragile / ce qui est contradictoire,
   - le lien réel (ou non) avec Machiavel,
   - vocabulaire à maîtriser,
   - pistes de contenu TikTok (posts, lives, débats).
4. Le `glossaire.md` accumule les concepts clés au fil des textes.
5. Plus tard : un dossier `contenus/` pour les scripts de posts et de lives.

## Arborescence

```
sources/     textes bruts reçus
analyses/    décryptages
glossaire.md concepts clés cumulés
```
