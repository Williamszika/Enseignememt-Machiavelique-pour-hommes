# File des thèmes : un script par jour

**Règle (décidée par Mr Zika le 18 octobre 2026) :** chaque jour, un thème de cette file devient un script vidéo (1 min 20 à 3 min : le thème affiché devant, une histoire émouvante, puis la motivation), écrit par l'agent expert en motivation dans `contenus/videos/2min/`. On prend toujours **le premier thème « à faire »**, dans l'ordre. Quand Mr Zika envoie un nouveau texte, le workflow `texte-vers-scripts` le lit et le sculpte, et ses thèmes s'ajoutent **à la fin** de cette file.

Les thèmes ci-dessous viennent de la **source 40** (le texte sur le stoïcisme), repérés par l'agent dans ses trois sculptures : [vidéo A](../../../analyses/40-sculpture-A.md), [vidéo B](../../../analyses/40-sculpture-B.md), [vidéo C](../../../analyses/40-sculpture-C.md). On alterne les trois vidéos, du thème le plus fort au moins fort.
